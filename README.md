packagist-crawler
========================

**This repository is archived.**

Packagist 1.x metadata is no longer provided by packagist.org. This tool was used to mirror the Packagist v1 API, which is now deprecated and discontinued. The Packagist.JP mirror service has been shut down.

For current usage, please use the official [packagist.org](https://packagist.org).

---

This tool crawled packagist.org and downloaded all package.json files to create a mirror of Packagist v1 API. License: CC0-1.0.
